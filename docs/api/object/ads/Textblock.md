# Textblock

An object that describes blocks of text content.

Used in objects: [Banner](https://ads.vk.com/en/doc/api/object/Banner), [BannerMassAction](https://ads.vk.com/en/doc/api/object/BannerMassAction)

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| text | allowedchars | readablewritabledefault\_field | Ad text |
| title | allowedchars | readablewritabledefault\_field | Ad title |
