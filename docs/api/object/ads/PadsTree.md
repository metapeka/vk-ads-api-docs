# PadsTree

The object contains information about pad trees.

Used in resources: [PadsTree](https://ads.vk.com/en/doc/api/resource/PadsTree)

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| id | id | readabledefault\_fieldmin\_value=1max\_value=2147483647 | Pad tree ID |
| tree | string | readabledefault\_field | Pad tree. Each element contain either the "id" field that specifies a pad ID, or the "children" field that contains an array of child pads. |
