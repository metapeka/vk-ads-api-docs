# SurveyConditionAnswerExists

An object representing a condition that checks whether the respondent's answer to a question contains the specified option.

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| question\_answer\_id | string | readablewritablerequired | Identifier of the [answer option](https://ads.vk.com/en/doc/api/object/SurveyQuestionAnswer) |
| question\_block\_id | string | readablewritablerequired | Identifier of the [question block](https://ads.vk.com/en/doc/api/object/SurveyBlock) |
