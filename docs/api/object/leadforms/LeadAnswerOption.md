# LeadAnswerOption

An object describing the answer option selected by the lead.

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| id | string | readable | The identifier of the answer option |
| text | string | readable | The text of the answer option. This is what is visible when the form is displayed. If this option implies a free-form answer, then the lead's answer will not be present here |
