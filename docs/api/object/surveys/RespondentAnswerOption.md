# RespondentAnswerOption

An object describing an answer option selected by the respondent.

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| id | string | readable | Answer option identifier |
| text | string | readable | Answer option text. This is what is shown when the survey itself is displayed. If this option implied a free-text answer, the respondent's actual answer will not be present here. |
