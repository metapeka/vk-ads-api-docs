# LeadContactInfo

An object describing a lead's contact details.

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| first\_name | string | readablenullable | Lead's first name |
| email | email | readablenullable | Lead's email address |
| phone | phone | readablenullable | Lead's phone number in the format +xxxxxxxxxxx |
| birth\_date | date | readablenullable | Lead's date of birth |
| city | string | readablenullable | Lead's city of residence |
| social\_media\_profile | string | readablenullable | Link to the lead's social media profile |
