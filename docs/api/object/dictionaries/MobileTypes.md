# MobileTypes

An object containing information about mobile device types.

Used in resources: [MobileTypes](https://ads.vk.com/en/doc/api/resource/MobileTypes)

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| description | string | readabledefault\_field | Device type description |
| id | string | readabledefault\_field | Internal unique identifier of the device type |
