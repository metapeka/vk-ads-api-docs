# AdditionalClientInfo

The object contains additional data on an agency client.

Used in objects: [UserClient](https://ads.vk.com/en/doc/api/object/UserClient), [UserManagerClient](https://ads.vk.com/en/doc/api/object/UserManagerClient)

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| address | string | readable | Address. |
| client\_info | text | readablewritable | Agency notes on the client. |
| client\_name | text | readablewritable | Agency client name. |
| name | string | readable | First and last names. |
| phone | string | readable | Phone. |
