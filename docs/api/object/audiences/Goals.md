# Goals

The object contains descriptions of the goals arranged by the types available in the user campaigns.

Used in resources: [Goals](https://ads.vk.com/en/doc/api/resource/Goals)

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| mobile\_install | list of [Goal](https://ads.vk.com/en/doc/api/object/Goal) | readabledefault\_field | The goal is the number of installations of the advertised mobile app. |
| ok\_game | list of [Goal](https://ads.vk.com/en/doc/api/object/Goal) | readabledefault\_field | The goal is the number of installations of the advertised Odnoklassniki app. |
| ok\_group | list of [Goal](https://ads.vk.com/en/doc/api/object/Goal) | readabledefault\_field | The goal is the number of new memberships in the advertised group in Odnoklassniki. |
| topmailru | list of [CounterGoal](https://ads.vk.com/en/doc/api/object/CounterGoal) | readabledefault\_field | The goals available for the [Top@Mail.ru](https://top.mail.ru/) counters. |
