# MobileCategory

The object contains data on mobile app category.

Used in resources: [MobileCategory](https://ads.vk.com/en/doc/api/resource/MobileCategory)

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| id | id | readabledefault\_fieldmin\_value=1max\_value=2147483647 | Unique system identifier of the mobile app category. |
| name | string | readabledefault\_field | Category name. |
| platform | string | readabledefault\_field | Category platform (Android/iOS). |
| type | string | readabledefault\_field | Category type (app/game). |
