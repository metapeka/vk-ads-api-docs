# AuditPixel

An object containing information about audit pixels.

Used in objects: [AdGroup](https://ads.vk.com/en/doc/api/object/AdGroup)

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| audit\_pixel | url | readablerequiredwritable | Audit pixel URL |
| role | string | readablerequiredwritable | Event that triggers this audit pixel |
