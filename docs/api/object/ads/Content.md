# Content

The object provides information about an uploaded creative.

Used in resources: [Content](https://ads.vk.com/en/doc/api/resource/Content)

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| id | id | readabledefault\_fieldmin\_value=1max\_value=2147483647 | Creative ID. |
| variants | relatedobject | readabledefault\_field | List of available creative formats. Upon the first upload of the creative will contain only the source creative parameters: width, height, size, and address. |
