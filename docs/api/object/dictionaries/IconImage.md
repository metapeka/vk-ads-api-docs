# IconImage

The object contains data on the mobile app banner image.

Used in objects: [GoogleApp](https://ads.vk.com/en/doc/api/object/GoogleApp), [AppleApp](https://ads.vk.com/en/doc/api/object/AppleApp)

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| height | integer | readablerequireddefault\_fieldmin\_value=-2147483647max\_value=2147483647 | Height (pixels). |
| id | id | readabledefault\_fieldmin\_value=1max\_value=2147483647 | Unique system ID of the image. |
| preview\_url | string | readablerequireddefault\_field | Image URL. |
| size | integer | readablerequireddefault\_fieldmin\_value=-2147483647max\_value=2147483647 | Size (bytes). |
| width | integer | readablerequireddefault\_fieldmin\_value=-2147483647max\_value=2147483647 | Width (pixels). |
