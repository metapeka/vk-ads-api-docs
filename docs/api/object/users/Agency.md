Used in objects: [User](https://ads.vk.com/en/doc/api/object/User), [User](https://ads.vk.com/en/doc/api/object/User), [NestedUser](https://ads.vk.com/en/doc/api/object/NestedUser)

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| buyer\_commission | decimal | readabledefault\_field | Buyer commission. |
| is\_buyer | boolean | readabledefault\_field | Flag that indicates that the agency is the buyer. |
| overriding\_commission | decimal | readabledefault\_field | Commission. |
