# PackagePad

Description of the pads used in the default package targetings.

Used in resources: [PackagesPads](https://ads.vk.com/en/doc/api/resource/PackagesPads)

| Field name | Type | Conditions | Description |
| --- | --- | --- | --- |
| description | string | readabledefault\_field | Pad description. |
| eye\_url | object | readabledefault\_field | URL of the pad where the ad is located. Possible keys: "id", "description", "url". |
| id | id | readabledefault\_fieldmin\_value=1max\_value=2147483647 | Pad ID. |
| name | string | readabledefault\_field | Pad name. |
| patterns | string | readabledefault\_field | Supported banners patterns on pad. |
